# Chaturbate on Potplayer

### Detect supported live stream sources and play them directly in PotPlayer.

"Chaturbate on Potplayer" is a Chrome extension designed for Windows PC users who prefer using PotPlayer as their external media player.

The extension helps identify available stream sources on supported live-stream pages. Select a detected source and open it in PotPlayer with a simple click.

## Features

### 1. Stream Source Detection
Detects available stream sources on supported live-stream pages.

### 2. Source Selection
Select an available stream source directly from the extension interface.

### 3. One-Click Playback
Open the selected stream in PotPlayer without manually copying and pasting stream URLs.

### 4. Simple Workflow
Use Chrome to detect and select sources while PotPlayer handles playback.

## How It Works

1. Open the "Chaturbate" website in Google Chrome.
2. Install the "Chaturbate on Potplayer" extension in Chrome.
3. Allow the extension to detect available stream sources.
4. Select a source and click "Play".
5. PotPlayer opens the selected stream.

## System Requirements

- Windows PC
- Google Chrome desktop browser
- PotPlayer installed
- Internet connection
